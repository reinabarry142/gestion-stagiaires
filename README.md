# Application de gestion des stagiaires – Smart IT Partner

## Description
Cette application web permet à Smart IT Partner de gérer efficacement les stagiaires de l'entreprise. L'administrateur peut créer, lire, mettre à jour et supprimer les informations des stagiaires via une interface simple et sécurisée.

## Fonctionnalités principales
- **Gestion CRUD des stagiaires** :
  - Nom et prénom
  - Date de naissance
  - Niveau d'étude
  - École ou faculté
  - Prochain diplôme
  - Année d'étude
  - Photo
- **Espace administrateur sécurisé** pour accéder et modifier les informations.
- **Interface web intuitive** pour faciliter la gestion quotidienne des stagiaires.

## Technologies utilisées
- **Frontend** : HTML, CSS, JavaScript
- **Backend** : PHP
- **Base de données** : MySQL
- **Gestion des fichiers** : Upload et stockage des photos des stagiaires
